# Piper Norwegian voice models

Download the Bokmål medium voice:

```bash
cd backend
source .venv/bin/activate
python -m piper.download_voices no_NO-talesyntese-medium --data-dir models
```

Expected files:

- `no_NO-talesyntese-medium.onnx`
- `no_NO-talesyntese-medium.onnx.json`
